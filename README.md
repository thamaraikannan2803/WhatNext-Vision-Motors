# WhatNext-Vision-Motors


🚗 WhatNext Vision Motors

Salesforce Vehicle Management System

A Salesforce-based Vehicle Management System developed to automate vehicle sales, dealer assignment, test drive scheduling, and service request management using Salesforce Apex, Flows, Triggers, and Lightning Web Components (LWC).

---

📌 Project Overview

WhatNext Vision Motors is designed to streamline vehicle dealership operations by managing customers, vehicles, dealers, vehicle orders, test drives, and service requests within the Salesforce platform.

The project leverages Salesforce automation to reduce manual work, improve customer experience, and provide a centralized dashboard for monitoring vehicle-related activities.
